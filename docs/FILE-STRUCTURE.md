# Top Gun Simulator: File Structure

```
Package.swift                     Swift package: FlightCore library, TopGunSimulator app, tests
top_gun_simulator.md              Project brief, assumptions and changelog
README.md                         At-a-glance overview with screenshots
Resources/AppIcon.icns            App icon (generated by scripts/make-icon.swift)

Sources/FlightCore/               Pure simulation, no UI
  Math.swift                      Vector and quaternion aliases, units, axes, seeded RNG
  Environment.swift               Atmosphere, terrain height field and runway, wind and turbulence
  AircraftSpec.swift              Trainer and fighter data (mass, aero derivatives, gear, speeds)
  FlightModel.swift               Aircraft state, 6-DOF physics step, control laws, gear, touchdown and crash
  Telemetry.swift                 Cockpit-unit snapshot used by UI, lessons and instructor
  Instructor.swift                Live hints with "why" explanations
  Lessons.swift                   Lesson model, progress tracking and the 11-lesson catalog
  Session.swift                   FlightSession, canyon gates, bandit AI, guns, events
  OnScreenControls.swift          On-screen stick mapping and merge into the pilot input
  TiltMapping.swift               Controller tilt: gravity vector → stick, calibration

Sources/TopGunSimulator/          The Mac app
  TopGunSimulatorApp.swift        App entry, menus, Settings scene, launch flags
  SimulationController.swift      Frame loop, events, toasts, snapshots for SwiftUI
  InputManager.swift              Keyboard and game-controller input
  WorldScene.swift                SceneKit world: terrain, airport, PAPI, gates, cameras, effects
  AircraftModels.swift            3D trainer and fighter with moving control surfaces
  FlightView.swift                Flight screen layout, toolbar, result and pause overlays
  HUDView.swift                   Head-up display
  OnScreenControlsView.swift      Mouse/trackpad stick, rudder, throttle and buttons
  InstrumentPanel.swift           Six-pack gauges and controls readout
  SidebarView.swift               Lesson, free-flight and instructor panels
  MapViews.swift                  2D moving map and side profile
  HomeView.swift                  Start screen with lesson cards
  SettingsView.swift              Settings tabs and the controls help sheet
  FeedbackTab.swift               Feedback button and local store
  AppSettings.swift               Settings keys, defaults, lesson progress, unit formatting
  Theme.swift                     Category, hint and HUD colours (light and dark)

Tests/FlightCoreTests/
  FlightModelTests.swift          Physics, session, lesson and AI tests
  GoldenExportTests.swift         Exports reference trajectories for the web port (opt-in)
  OnScreenControlsTests.swift     On-screen controls: stick mapping and input merging
  TiltMappingTests.swift          Controller tilt maths

web/                              The website (TypeScript + Three.js + Vite)
  index.html                      Page shell: home, flight screen, dialogs
  package.json, vite.config.ts    Build setup (PAGES_BASE sets the Pages sub-path)
  public/favicon.svg              Icon
  src/main.ts                     Frame loop, home screen, sidebar, overlays, settings/help/feedback dialogs
  src/style.css                   Layout and colour tokens (light + dark)
  src/core/                       Port of FlightCore: math, environment, aircraft, telemetry,
                                  instructor, lessons, session (same maths, line for line)
  src/app/world.ts                Three.js world: terrain, airport, PAPI, gates, cameras, effects
  src/app/models.ts               3D trainer and fighter with moving control surfaces
  src/app/hud.ts                  Head-up display
  src/app/instruments.ts          Six-pack gauges and controls readout
  src/app/maps.ts                 2D moving map and side profile
  src/app/input.ts                Keyboard and Gamepad API (merges touch input)
  src/app/touch.ts                On-screen stick, rudder, throttle and buttons for phones and tablets
  src/app/tilt.ts                 Tilt-to-fly: motion sensor → stick, calibration, permission
  src/app/settings.ts             localStorage settings, lesson progress, unit formatting
  src/app/frame.ts, icons.ts      Per-frame snapshot type, canvas helper, SVG icons
  tests/golden.test.ts            Replays the Swift reference trajectories
  tests/core.test.ts              Ports of the key Swift tests
  tests/touch.test.ts             Touch stick maths, input merging and touch wording
  tests/tilt.test.ts              Tilt maths and tilt input merging
  tests/fixtures/golden.json      Reference trajectories exported from Swift

.github/workflows/pages.yml       Test, build and deploy the website to GitHub Pages

scripts/
  build-app.sh                    Builds build/Top Gun Simulator.app
  make-icon.swift                 Draws the app icon
  screenshot.sh                   Launches with flags and captures the window

docs/
  INSTRUCTIONS.md                 Setup, run, controls, how to learn
  SYSTEM-DESIGN.md                Architecture, flows, decisions, testing, limits
  FILE-STRUCTURE.md               This file
  screenshots/                    Images used by the README
```
